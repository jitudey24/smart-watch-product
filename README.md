# Smartwatch Product Page

A product showcase page for a modern smartwatch. The interface presents product imagery and product information in a responsive layout.

## Features
- Smartwatch product presentation
- Product image area
- Responsive two-column layout on larger screens
- Tailwind CSS utility styling
- Font Awesome icon support

## Technologies
- HTML5
- Tailwind CSS
- Font Awesome

## Run Locally
1. Clone this repository.
2. Keep the `images` directory and product images in place.
3. Open `index.html` in a modern browser.
4. An internet connection is needed to load the CDN assets.

## Project Purpose
This project practices product-page composition, responsive layouts, and utility-first styling.
